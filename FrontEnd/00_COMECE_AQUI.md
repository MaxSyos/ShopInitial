## 🎯 COMO COMEÇAR

### 1. Acessar a Página
```
http://localhost:3000/create-product
```

### 2. Preencher Dados
```
Nome: (obrigatório)
Preço: (obrigatório)
Estoque: (obrigatório)
Descrição: (opcional)
SKU: (opcional)
Categoria: (opcional)
Marca: (opcional)
```

### 3. Upload de Imagens
```
Clique ou arraste
Máximo 5 imagens
Máximo 5MB por imagem
```

### 4. Submeter
```
Clique em "Criar Produto"
Aguarde validação
Será redirecionado para /products
```
