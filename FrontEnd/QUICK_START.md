# ⚡ GUIA RÁPIDO - 5 MINUTOS

## 🎯 Começar em 5 Minutos

### 1️⃣ Acessar (30 segundos)
```
http://localhost:3000/create-product
```

### 2️⃣ Preencher (2 minutos)
```
Nome:     "iPhone 14 Pro"
Preço:    "3999.99"
Estoque:  "50"
```

### 3️⃣ Imagens (2 minutos)
```
Clique na área cinzenta
Selecione uma imagem (PNG, JPG)
Aguarde o upload
```

### 4️⃣ Submeter (30 segundos)
```
Clique em "Criar Produto"
Pronto! ✅
```

## ⚙️ Configuração Rápida

### Sem Configuração (Pronto Agora)
```
✅ Funciona imediatamente
✅ Sem API key necessária
✅ Limite gratuito do ImgBB
```

### Com API Key (Opcional para Produção)
```
1. Vá para https://imgbb.com
2. Crie conta gratuita
3. Copie API key em https://api.imgbb.com
4. Adicione em .env.local:
   NEXT_PUBLIC_IMGBB_API_KEY=sua_chave
```

## 🐛 Problemas Comuns

| Problema | Solução |
|----------|---------|
| "Imagem muito grande" | Comprima para <5MB |
| "Erro no upload" | Verifique internet |
| "Campos obrigatórios" | Preencha nome, preço, estoque |
| "Sem imagens" | Adicione pelo menos 1 imagem |
